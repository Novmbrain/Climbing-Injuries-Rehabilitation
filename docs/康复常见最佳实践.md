# 攀岩常见伤病来源

随着水平提升，攀岩的运动强度会快速增加。攀岩是一项对全身综合能力要求极高的运动，每个人的身体条件和强项各不相同。如果综合能力没有同步发展，某些薄弱环节就会在高强度下暴露出来，从而增加受伤的风险。

### 1. 身体适应速度不一致

身体各部分的适应速度并不一致。

- **肌肉**：通常能较快地增强，比如是手指屈肌、前臂和背部肌群。
- **结缔组织和韧带**：强化过程较慢，需要更多时间适应拉力和扭力。
   当攀岩难度持续提高时，如果肌肉力量已经足以完成动作，但结缔组织和韧带还没跟上，就容易出现伤病，如手指滑车炎、肘部肌腱炎、膝关节不适等。

### 2. 局部过度使用（慢性损伤）

对某一身体部位持续施加高强度、频繁的应力，也会造成慢性损伤。

- **训练量和强度失衡**：反复攀爬同一条线路、重复相似动作（如锁定、勾挂脚、动态冲坠），使局部组织超负荷，导致微损伤积累。
- **恢复不足**：没有安排足够的休息和恢复日，组织还没修复就再次施压，造成慢性炎症或疲劳性损伤。
- **单一动作模式**：长期练习某一种攀爬风格（如持续抱石爆发力训练）可能忽视其他肌群，导致失衡和受伤风险上升。

### 3. 技术与动作习惯问题

- **不合理的身体姿势**：如强行扭膝、锁肩、暴力拉拽，增加关节和韧带压力。
- **缺乏技术多样性**：技术不够成熟，遇到高难动作时只能“硬拉”，用蛮力代替效率动作，导致受伤风险高。
- **忽视核心和下肢发力**：仅依赖手臂拉力，而非全身协同，给手指、肩膀、肘部过大压力。

### 4. 热身和放松不足

- **缺乏系统热身**：直接上高强度线路，导致肌腱和关节未进入状态，易拉伤。
- **训练后不放松**：不做拉伸或放松，肌肉长期紧张，影响血液循环和恢复。

### 5. 自我保护意识不足

- 抱石下落动作不规范，容易造成脚踝或膝盖扭伤。
- 运动攀冲坠没有合理落点意识，可能碰墙、撞膝盖。
- 忽视疲劳信号，在状态不佳时继续高强度训练，导致过劳伤。

### 6. 装备和环境因素

- **鞋子不合脚**：挤压导致趾关节或足底筋膜炎。
- **攀岩场地条件差**：落点硬、支点打磨不均匀，也可能诱发意外伤。

### 7. 心理因素

- **过度追求难度**：急于升级难度，没有给身体足够适应时间。
- **忽视身体信号**：为了“刷完课题”，忍痛攀爬，最终导致更严重伤病。
- **压力和紧张**：精神紧绷可能导致动作僵硬、保护意识下降，意外风险增加。

### 8. 纯意外

即使技术和训练都合理，意外也可能发生，比如支点断裂、意外滑落、保护员失误等。

# 通用康复流程

康复的核心原则：
 **消炎 → 休息 → 功能恢复 → 逐步回归运动**

> **恢复速度要快于训练刺激**，否则易复发。



## 以手指受伤举例  

### 1️⃣ 快速消炎期（急性期）

**目标：** 减轻炎症和疼痛，防止二次损伤。

- 停止所有相关训练（攀爬、挂力板、引体等）
- 可局部使用消炎药膏（如扶他林）或活络油
- 轻柔按摩受伤部位周围，避开痛点，促进血液循环
- 若有肿胀，可冰敷 10–15 分钟，每天 2–3 次

------

### 2️⃣ 主动休息期（保护期）

**目标：** 避免再次拉伤，维持身体整体训练状态。

- 避免对受伤部位的负重，必要时可使用指环/夹板保护
- 进行不影响受伤部位的训练，如核心、腿部、肩部、静态支撑
- 开始轻度被动活动（弯曲、伸展），保持在无痛范围内
- 保持休息与轻度活动交替，促进局部代谢

------

### 3️⃣ 康复训练期（功能恢复期）

**目标：** 恢复受伤部位功能、力量和协调性。

- 开始等长收缩训练，如用指垫轻压墙壁或橡皮泥，保持 5–10 秒
- 使用橡皮筋或弹力球进行手指抗阻训练，逐渐增加阻力
- 从低负载 open-hand grip 开始，观察疼痛反应
- 控制疼痛在 1/10 以下，出现剧痛应停止
- 可尝试轻量挂力板测试：1–3 秒 open-hand 挂，无不适再继续
- 禁止 crimp（实指扣），直到完全无痛且肌腱恢复弹性

------

### 4️⃣ 逐步回归攀爬

**目标：** 安全、循序渐进地回到正常训练量。

- 从简单线路开始（抱石 V0–V2 / 运动攀 5a–5c）
- 以 open-hand grip 为主，避免剧烈锁定和动态 crimp
- 控制攀爬时间和强度，建议低于平时 50%
- 每次攀爬后记录疼痛、肿胀、僵硬感，持续观察
- 连续两周无复发，再逐渐恢复至正常训练量

### 小贴士

- 循序渐进比快速恢复更重要，宁可慢两周，也不要复发
- 疼痛是身体信号，不是挑战

# 🧗‍♀️ 合理安排训练：

- 热身要完整、有针对性  
- session 中段是状态最好时段  
- session 后做简单线路进行“收身”
